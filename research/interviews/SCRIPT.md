# SCRIPT — 30-min Interview (R0)

**Use:** 5 target users. **Language:** follow the user (ID default, EN if they prefer, campur OK). **Record:** phone voice-note or GMeet record. Total 30 min — keep time!

Maps to PRODUCT.md §9 (5 open Qs) + TASK.md §2 R0 accept (3/5 would-try, top-10 commands, agent pick) + R0-pack §c (blob vs robot) + §g (price/fear survey).

This is research only, no sales. 30 minutes, 10 questions + a quick paper test. May I record/notes? Anonymized — your name won't appear in reports. You can skip any question or stop anytime. OK to continue?"

Ini murni riset, bukan jualan. 30 menit, 10 pertanyaan + 1 tes gambar. Boleh aku rekam/catat? Anonim — nama kakak nggak muncul di laporan. Boleh skip/stop kapan aja. Lanjut ya?"

☐ Consent yes → start timer. ☐ Notes or recording on.

## 3–20 min — 10 core questions (→ maps to §9)

**Work context (→ §9-Q3: where + noise)**
1. "Where do you actually work in a week? Which kos/cafe/coworking, how often?" / "Seminggu kerja di mana aja? Kos/cafe/coworking apa, berapa kali?" — probe: table size, wall space, WiFi, colokan. Noise: "Seberapa berisik tiap lokasi (kipas kos, mesin kopi, orang ngobrol)? 1=sunyi, 5=ramai."
2. "Walk me through yesterday's standup: where, how long, what tool (WA/Discord/Notion/GMeet)? What annoyed you?" / "Ceritain standup kemarin: di mana, berapa lama, pakai apa? Apa yang paling nyebelin?"

**Commands (→ top-10 lock, R0-pack §a)**
3. "If you could TALK to your work instead of typing — what 3 things would you say every morning?" / "Kalau kerjaan bisa disuruh ngomong, 3 perintah apa yang tiap pagi kakak ucapkan?" — list verbatim, then probe each of the 10: wake / run / stop / move-to-wall / summarize / assign / remind / next / done / focus.
4. "Voice in English only, or campur Indonesia? Try saying: 'Jalankan tes landing' vs 'Run landing test' — which feels natural?" / bilingual probe per R0-pack §a.

**Agent look (→ §9-Q1, showcard — read both options neutrally)**
5. 📋 SHOWCARD (print or share screen, read verbatim):
   - **A — Blob:** "Three small soft blob creatures (blue/green/amber), squash-and-stretch, breathe when idle, glow when working. Cute like Pokémon staff."
   - **B — Robot:** "Three small metal robots, rigid arms, lights blink when working. Precise like gadgets."
   "Which would you trust to run YOUR standup task — A or B, and why? Would cute blob feel less serious?" / "Mana yang kakak percaya buat jalanin tugas — A atau B, kenapa? Apa blob lucu terasa kurang serius?"

**Price (→ §9-Q4, R0-pack §g-Q1)**
6. "Horizon Workrooms is free (but shutting down Feb 16). If Virtual Loft costs $15/user/mo (~240k IDR) for 15-min standup with zero rescan — $0 vs $15 vs $30: which would you expense, and what must it do to be worth $15?" / ID: "Workrooms gratis (tapi tutup Feb 16). Kalau Loft bayar 240rb/user/bln — pilih gratis / 240rb / 480rb? Harus bisa apa biar worth 240rb?" — kill $30 if 0/5 bite.

**Fears (→ §9-Q5, R0-pack §g-Q2–Q4)**
7. Sickness: "Have you felt VR nausea? Would seated-only + teleport-only + 15 min change your answer?" / "Pernah mabuk VR? Kalau cuma duduk + teleport + 15 menit, berubah?"
8. Silly-look: "Wearing Quest for standup in kos/cafe — silly 1–5? What would make it normal?" / "Pakai Quest buat standup di kos/cafe — malu 1–5? Biar normal gimana?"
9. Team adoption: "Who is the ONE teammate that must join for this to be worth it? What would convince them?" / "Siapa SATU orang yang wajib ikut biar worth it? Biar dia mau, gimana?"

**Try test (→ R0 gate, R0-pack §g-Q5)**
10. "If the loft loads identical in kos/cafe/hotel with zero rescan — would you try tomorrow's standup in VR? Yes/no, biggest doubt?" / "Kalau loft kebuka sama persis di kos/cafe/hotel tanpa setting — mau coba standup besok di VR? Ya/tidak, ragu terbesar apa?"

## 20–27 min — Figma/paper loft test protocol (<30s rule, TASK.md §7)

Setup: show paper print or Figma: 1 curved wall (Kanban left, Notes center, Calendar + Log right), 3 desks (Scout-blue left, Builder-green center, Keeper-amber right).

Script: "No tutorial. You are the boss. Point at Builder (green, center) and say the command to run a test." / "Tanpa tutorial. Kakak bosnya. Tunjuk Builder (hijau, tengah) dan ucapkan perintah buat jalanin tes."

- Start stopwatch. ✅ Pass = points at correct agent + says run-like command ("run test" / "jalankan tes") in <30s.
- Record: time ___s, pointed correct? (y/n), phrase said verbatim: "___".
- If fail (>30s or wrong agent): note where confused, then teach once and retry (record retry too).
